# AirVeil 0.11.1 beta 1

First downloadable Apple silicon build. This is a prerelease; physical AirPods acceptance testing is pending.

## Install

Download **AirVeil-0.11.1-apple-silicon.dmg**, open it, and drag **AirVeil.app** onto **Applications**. Quit an older copy before replacing it, then launch from Applications and eject the disk image.

Requires an Apple silicon Mac, macOS 14 or later, and compatible head-tracking AirPods. This app is development-signed, not Apple-notarized; macOS may block first launch on another Mac. Downloads require repository access while this repository is private.

## Included

- Notch camera, direction rail, conditional Face light controls, and green smile animation.
- Independent left/right blur-start angle dials.
- 0% seated-brightness option and original-brightness restoration.
- Guarded per-ear status reader, corrected cached-reading confirmation, and anonymous diagnostic hooks.
- Tracking recovery and unchanged-display-notification fixes.
- Clear separation between Enable blur and automatic removal handling. Screen Recording access is only needed for live desktop blur; processing stays on the Mac.

## Testing and limits

Automated core, camera/presence lifecycle, brightness ownership, GPU rendering, and native notch checks pass. The disk image was mounted read-only, its contents and Applications shortcut checked, and its packaged executable matched the signed build.

Independent removal of the non-tracking AirPod, physical 0% brightness/restoration, and live Activity Monitor behavior still need hardware testing. The per-ear reader depends on private compatibility APIs; unavailable metadata falls back to public headphone connection events. Seated dimming uses a confirmed removal event and does not enforce a both-AirPods-out requirement in this build. Automatic display sleep follows the Mac's password-on-wake settings; AirVeil never unlocks the Mac.

The DMG includes no local preferences, recordings, diagnostic logs, or signing keys.
