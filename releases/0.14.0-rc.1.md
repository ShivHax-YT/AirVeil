# AirVeil 0.14.0 RC 1

**[Download the macOS DMG](https://github.com/ShivHax-YT/AirVeil/releases/download/v0.14.0-rc.1/AirVeil-0.14.0-apple-silicon.dmg)**

Release candidate 1 for Apple silicon Macs running macOS 14 or later. App version 0.14.0, build 18.

## What changed

- Energy use offers Automatic, Smoothest, and Reduced energy. Automatic reduces desktop capture refresh in Low Power Mode or serious/critical thermal conditions.
- Capture updates apply without restarting working streams. Rapid changes are serialized; rejected energy updates retain functioning capture and show a status.
- Head tracking, coverage movement, camera checks, AirPod removal, and brightness timing retain their existing behavior.
- Includes the Settings spotlight walkthrough, notch tutorial, automatic Face light, and idle-audio/handoff improvements from the preceding releases.

## Install

Download the `.dmg` below, quit AirVeil, and drag AirVeil into Applications. Launch it from Applications. Existing preferences are retained. The `.sha256` sidecar verifies the download.

## Verification and limits

All core automated regression suites passed, including actual Metal rendering, capture policy/lifecycle, tracking, camera, removal, and brightness tests. Native checks passed 43 notch lifecycle cases and all 15 live Settings tutorial steps. The installed app passed energy selection, persistence across quit/relaunch, and simulated directional preview/center checks.

This RC label identifies the release candidate; physical AirPods, camera/low-light, removal/reinsertion, and battery-runtime acceptance remain pending. Energy savings are not yet measured. Development-signed and not Apple-notarized; another Mac may block first launch. Repository access is required while the repository is private.
